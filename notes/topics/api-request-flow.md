# 一次 API 请求经历什么

浏览器是客户端，后端程序是服务器。用户点击搜索按钮后，浏览器把请求发到一个 URL；服务器找到对应的路由，处理输入，再把结果发回来。网页和接口之间靠请求与响应交换数据。

GET 请求适合读取数据。搜索词可以放在查询参数中，例如 `/search?keyword=链接`。问号后面是参数，等号左边是名字，右边是值。浏览器发送中文或特殊符号时，需要先进行 URL 编码。

路由函数可以接收查询参数、检查空输入、调用搜索函数，然后返回字典。Web 框架会把字典序列化成 JSON；网页里的 JavaScript 再把 JSON 解析为对象，读取其中的 `results` 列表。

状态码描述请求是否成功。200 表示本次请求正常完成，400 表示输入不符合接口要求，500 通常表示服务器处理时出了问题。调试时要同时看状态码和响应内容，不能只看页面上有没有文字。

浏览器开发者工具的“网络”面板可以查看请求 URL、参数、状态码和响应。若页面没有显示结果，先确认请求是否发出，再看接口返回的 JSON，最后检查负责渲染结果的脚本。
