# CSAPP 第七章：链接练习笔记

一个 C++ 程序可以由多个源文件组成。每个源文件先分别编译成目标文件，最后由链接器把目标文件和需要的库组合起来，生成可执行程序。这样修改一个源文件时，通常只需重新编译受影响的部分。

函数名和全局变量名可以成为符号。如果 main.cpp 调用了 math.cpp 中定义的函数，链接器要根据符号信息找到正确的定义。声明告诉编译器这个函数存在，定义则提供函数的实际代码。

目标文件中的某些地址在编译时还不能最终确定。链接器安排好各部分的位置后，会修改代码或数据中引用地址的地方；这个过程叫重定位。重定位让不同目标文件中的代码能正确引用彼此。

静态库通常在链接时提供程序需要的代码；共享库则可以在程序加载或运行时使用。选择哪种方式会影响可执行文件的大小、部署方式，以及更新库时需要做的工作。

遇到 undefined reference 错误时，先检查函数是否真的有定义、对应的目标文件是否参与构建，以及函数名和参数是否一致。遇到 multiple definition 时，要检查是否在多个源文件中重复定义了同一个全局符号。
