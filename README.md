# 笔记搜索

一个从命令行练习发展成的小型检索项目：读取 `notes/` 里的笔记，按空行切分段落，再通过网页或 API 搜索。网页支持关键词、语义和组合三种方式。这个项目适合练习文件处理、函数拆分、FastAPI、前后端请求以及文本向量。

## 项目里有什么

| 文件 | 用途 |
| --- | --- |
| `main.py` | 扫描笔记文件、按关键词搜索、整理段落；也可以直接在终端运行。 |
| `semantic_demo.py` | 独立实验：用中文嵌入模型生成向量，并按余弦相似度排序。 |
| `api.py` | 提供网页、健康检查和三种搜索接口。 |
| `index.html` | 无构建工具的网页界面；样式和交互代码都在这个文件中。 |
| `eval_search.py` | 用 `TestClient` 请求组合搜索接口，检查预期段落是否排在第一位。 |
| `notes/` | 可搜索的 `.txt`、`.md` 笔记，包含 `topics/` 子目录。 |

概念和代码写法的解释见[项目知识点笔记](../learning-notes/note-search-project.md)。

## 安装与运行

建议使用 Python 3.12。若还没有环境，可以在终端创建；已有 `note-search` 环境则直接激活：

```powershell
conda create -n note-search python=3.12 -y
conda activate note-search
python -m pip install "fastapi[standard]" fastembed httpx
```

进入本项目目录，启动服务：

```powershell
python -m uvicorn api:app --reload
```

打开 <http://127.0.0.1:8000/> 使用网页，打开 <http://127.0.0.1:8000/docs> 查看并试用接口。首次启动会下载 `BAAI/bge-small-zh-v1.5` 中文嵌入模型；之后通常使用本地缓存。服务运行时，按 `Ctrl+C` 停止。

只想练习命令行搜索时，在项目目录运行 `python main.py`。输入关键词搜索，输入 `q` 退出；这一部分不需要启动网页服务。

## 三种搜索方式

| 方式 | 做什么 | 适合的输入 |
| --- | --- | --- |
| 关键词搜索 | 查找直接包含输入文字的段落；英文字母不区分大小写。 | 明确的术语、文件中出现的原词。 |
| 语义搜索 | 把问题和段落转换成向量，返回分数最高的 3 段。 | 与笔记意思接近、措辞不同的问题。 |
| 组合搜索 | 先放直接命中的段落，再用语义结果补足到 3 条，并去重。 | 不确定该用原词还是近义问法时。 |

可以先试“地址修正”：关键词搜索没有直接命中，语义和组合搜索应把 `csapp-linking-practice.md` 第 4 段排在前面。再试 `Python`：组合搜索会优先展示直接命中的 `python.txt` 段落。页面上的示例按钮也能一键填写这些问题。

**相似度分数只用于排序，不是答案正确概率。** 语义搜索会从现有笔记里挑出最接近的段落，即使问题与笔记无关，也可能返回结果。阅读原文、比较其他候选和准备评测用例都很重要。

## 添加自己的笔记

把 UTF-8 编码的 `.txt` 或 `.md` 文件放进 `notes/`，也可以放进子目录。段落之间留一个空行；程序会把每个非空段落当作一条检索记录。标题同样可能成为单独的段落。

关键词搜索每次请求都会重新读取文件。语义搜索的段落向量在服务启动时生成，因此添加或修改笔记后，请停止并重新启动服务，让语义和组合搜索使用新内容。

## API 速查

| 路径 | 作用 |
| --- | --- |
| `GET /health` | 确认服务是否正常运行，返回 `{"status": "ok"}`。 |
| `GET /search?keyword=重定位` | 返回所有直接命中的段落。 |
| `GET /semantic-search?query=地址修正` | 返回语义相似度最高的 3 段和分数。 |
| `GET /hybrid-search?query=地址修正` | 返回最多 3 条组合搜索结果，并标明 `source`。 |

空输入或只有空格的输入会返回 400。`/docs` 页面可以直接填写参数并查看 JSON 响应。

## 检查搜索结果

在项目目录运行：

```powershell
python eval_search.py
```

脚本用 FastAPI 的 `TestClient` 在 Python 进程内请求 `/hybrid-search`，不需要先启动 Uvicorn。它为每个问题记录一组可接受的“文件路径 + 段落编号”，检查返回的第一条是否在其中，最后打印 Top-1 命中率。一道题允许多个正确段落，例如“HTTP 请求成功的状态码”在两篇笔记中都有解释。

当前只有 5 道正例，输出的命中率只代表这组题。修改笔记或排序规则后可以重跑，观察哪些题发生变化。`api.py` 在导入时加载模型并生成段落向量，因此第一次运行脚本可能需要等待模型准备完成。当前评测用例中的子目录路径使用 Windows 的 `\` 分隔符，在其他系统运行时要留意路径格式。

下一步可以加入更多不同措辞的问题、检查 Top-3 是否命中，并单独记录没有相关答案的负例。负例不要计入现有的 Top-1 命中率。
